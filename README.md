# Site web de Fuse Consulting

Le futur site de [fuseconsulting.ca](https://fuseconsulting.ca), en HTML et CSS
écrits à la main, sans outil de construction.

- **Adresse de travail** : https://fuse-website-6lc.pages.dev — publiée par
  Cloudflare Pages à chaque modification de `main`. Le site public reste sur
  Squarespace jusqu'à la bascule du domaine.
- **Aperçus** : chaque proposition (pull request) reçoit sa propre adresse en
  `.fuse-website-6lc.pages.dev`, à vérifier avant publication.
- **Modifier le site** : par l'agent Claude Code défini dans
  [`CLAUDE.md`](CLAUDE.md) (version anglaise : [`CLAUDE.en.md`](CLAUDE.en.md)).
  Rien n'est publié sans un « OK publie » écrit d'une personne autorisée.
- **Journal des publications** : [`CHANGELOG.md`](CHANGELOG.md).

⚠️ Ce dépôt est public : rien de confidentiel n'y entre.
